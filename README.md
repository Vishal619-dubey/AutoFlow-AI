\# AutoFlow AI



\*\*Secure Document Intelligence and Workflow Automation\*\*



AutoFlow AI is a full-stack document automation platform built to make document processing more secure, verifiable and intelligent.



\[Live Demo](https://autoflow-ai-vishal.netlify.app) | \[Backend API](https://autoflow-ai-api.onrender.com)



\---



\## What AutoFlow AI Does



AutoFlow AI combines document automation, cloud security and AI in one workspace.



`Upload -> Analyze -> Encrypt -> Verify -> Automate -> Secure Access`



\---



\## Main Features



\- Intelligent Document Hub

\- Google Sign-In and JWT authentication

\- AES-256-GCM document encryption

\- Private AWS S3 storage

\- SHA-256 integrity verification

\- AutoFlow BioTrust with AWS Rekognition

\- Grounded PDF AI Copilot

\- Sensitive data detection

\- No-code automation rules

\- Human approval workflow

\- Security event monitoring

\- Mobile-friendly secure downloads



\---



\## AutoFlow BioTrust



BioTrust adds an extra identity check for sensitive documents.



For high-risk or critical downloads, AutoFlow AI can request face verification before allowing access.



`Login -> Risk Check -> Face Verification -> Integrity Check -> Secure Download`



\---



\## Security Model



| Security Goal | Implementation |

|---|---|

| Confidentiality | AES-256-GCM encryption and private AWS S3 |

| Authentication | JWT, Google Sign-In and BioTrust |

| Integrity | SHA-256 verification |
